# Framework Alignment

Use current official sources and record the version and verification date in the packet.

## K-12 route

Use the teacher's state or district standards when supplied. Otherwise, use CYBER.ORG's K-12
Cybersecurity Learning Standards as a national reference. Route across its major themes:

- Computing Systems
- Digital Citizenship
- Security

Do not invent an identifier or quote a standard from memory. Retrieve or verify the exact wording
before including it. If verification is unavailable, label the mapping as provisional and describe
the concept without fabricating a code.

Official entry point: https://cyber.org/initiatives/standards

## Workforce route

Use the NICE Workforce Framework for Cybersecurity for college, career, professional, and
work-based learning. Map in this order:

1. Competency Area or Work Role, when relevant.
2. Task statement describing the work learners will practice.
3. Knowledge statements required for that task.
4. Skill statements demonstrated through observable evidence.

Assess performance at the task or skill level. Do not treat a Work Role title as a learning
objective.

NICE components update independently. Verify the current component version and exact statements
from NIST before use.

Official entry points:

- https://www.nist.gov/itl/applied-cybersecurity/nice/nice-framework-resource-center
- https://www.nist.gov/itl/applied-cybersecurity/nice/nice-framework-resource-center/nice-framework-current-versions

## Certification route

Use the current objective document published by the certification owner. Record the exam code and
objective version. Map certification objectives in addition to, not instead of, observable lesson
evidence. Do not claim that one lesson prepares a learner to pass an exam.

## Alignment record

For each mapping, store:

- Framework or certification owner
- Framework/version or exam code
- Identifier
- Exact or faithfully paraphrased statement
- Lesson evidence that demonstrates the mapping
- Source URL
- Date verified

Remove mappings that are merely topical and not demonstrated by the learner task.
