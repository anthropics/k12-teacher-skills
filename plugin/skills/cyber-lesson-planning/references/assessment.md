# Cybersecurity Assessment

## Performance task

Write the assessment as:

> Given [authorized environment or supplied artifact], perform [defensive task], submit [evidence],
> and justify [decision or recommendation] under [constraints].

The task must require observable action, not only recall.

## Default rubric dimensions

Use four performance levels with observable descriptors:

1. **Technical accuracy** - findings and actions are correct.
2. **Evidence use** - conclusions point to relevant artifacts or observations.
3. **Defensive reasoning** - recommendations fit the risk and constraints.
4. **Safe practice** - work remains within scope and handles data appropriately.
5. **Communication** - another person can understand and act on the result.

Add tool fluency only when tool use is part of the outcome. Do not award points for decorative
formatting unless communication design is explicitly taught.

## Alignment rule

Every rubric row must identify the learner artifact it scores. Every required artifact must appear
in the learner instructions. Remove hidden requirements.

## Formative checks

Include at least one check before independent performance:

- Predict an observation.
- Identify the authorized scope.
- Explain what a command or control changes.
- Distinguish relevant from irrelevant evidence.
- Choose a safe next step.

## Feedback

Give feedback in this order:

1. Safety or scope violations
2. Incorrect evidence or technical reasoning
3. Missing task evidence
4. Communication improvement
5. Transfer or extension
